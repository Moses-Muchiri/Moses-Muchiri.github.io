I'm a medical student who writes code: mostly Python, some machine learning, and the odd capture-the-flag. This blog is where the write-ups and notes end up.

## Languages and tools

Python, Rust, JavaScript, HTML and CSS, SQL and Jupyter; PyTorch for machine learning; Linux and Git for everything else.

## Projects

- [Capacitation modelling](https://github.com/Moses-Muchiri/Capacitation_Modelling): a PySB model of sperm capacitation and motility under different biochemical conditions, built to learn biochemical modelling in code.
- [CO₂ emissions predictor](https://github.com/Moses-Muchiri/CO2_Emissions): regression models forecasting Kenya's CO₂ emissions, framed around SDG 13.
- [COVID-19 data tracker](https://github.com/Moses-Muchiri/COVID-19_Global_Data_Tracker): a notebook tracking global cases, deaths and vaccinations over time.
- [Power outage alerts](https://github.com/Moses-Muchiri/Power_Outage_Alerts): watches KPLC's announcements for planned outages and forwards them to Telegram.
- [Telegram shell bot](https://github.com/Moses-Muchiri/Telegram_To_Shell_Bot): runs shell commands from a Telegram chat, for reaching my machines remotely.
- [Library database](https://github.com/Moses-Muchiri/LMS-Database): a library management schema covering the catalogue, members and loans.
- [CryptoBuddy](https://github.com/Moses-Muchiri/CryptoBuddy): a rule-based chatbot that rates coins on price trend and sustainability.
- [W1seGuy solver](https://github.com/Moses-Muchiri/thm-W1seGuy): the code behind the [W1seGuy write-up]({% post_url 2026-10-28-tryhackme-w1seguy %}).
